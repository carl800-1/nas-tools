## 1. Product Overview
新能源行业电动工具使用情况PPT展示应用，提供交互式的行业分析、工序解析和工具分类展示。
- 主要目的：帮助用户了解新能源行业（光伏、新能源汽车制造等）电动工具使用种类和样式
- 目标用户：行业分析师、工具采购人员、生产管理人员
- 市场价值：提供专业的行业工具需求分析，助力生产效率提升

## 2. Core Features

### 2.1 Feature Module
1. **封面页**：项目标题、摘要信息
2. **行业分类页**：光伏、新能源汽车等行业分类展示
3. **工序分析页**：各行业主要生产工序详细说明
4. **工具分类页**：电动工具分类展示，重点是无绳工具
5. **数据总结页**：行业工具使用趋势总结

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 封面页 | Hero区域 | 项目大标题、副标题、日期信息 |
| 行业分类页 | 行业卡片 | 各新能源行业卡片展示，包含行业简介 |
| 工序分析页 | 工序列表 | 各行业生产工序详情，配有图标 |
| 工具分类页 | 工具展示 | 电动工具分类网格，包含无绳工具重点展示 |
| 数据总结页 | 总结图表 | 关键数据可视化展示 |

## 3. Core Process
用户通过导航栏或滑动浏览各页面，了解从行业分类到工具使用的完整分析。

```mermaid
flowchart LR

    D --> E[数据总结页]
```

## 4. User Interface Design
### 4.1 Design Style
- 主色调：科技蓝(#1e40af) + 活力绿(#10b981)
- 按钮风格：圆角矩形，有悬停效果
- 字体：Playfair Display（标题）+ Inter（正文）
- 布局风格：卡片式布局，网格排列
- 图标风格：简洁线条图标

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 封面页 | Hero区域 | 大字体标题，渐变背景，简洁动画 |
| 行业分类页 | 行业卡片 | 卡片网格，行业图标，悬停效果 |
| 工序分析页 | 工序列表 | 时间线样式，工序图标，详情展开 |
| 工具分类页 | 工具展示 | 工具分类标签，工具卡片网格 |
| 数据总结页 | 总结图表 | 数据可视化图表，关键指标卡片 |

### 4.3 Responsiveness
- 桌面端优先设计
- 响应式适配平板和移动端
- 触摸优化的交互体验
